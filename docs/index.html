🍔 CloudEats

A microservices-based food ordering platform built with Node.js, Docker, MySQL, and Redis.

Node.js Docker MySQL Redis GitHub Actions

Architecture

  • User Service — Register and login, port 3001
  • Menu Service — Menu browsing, port 3002
  • Order Service — Redis cart + MongoDB orders, port 3003

Quick Start

git clone https://github.com/YOUR-USERNAME/cloudeats-app
cd cloudeats-app
# create a .env file (see Week 7), then:
docker compose up -d
